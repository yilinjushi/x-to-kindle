# 有人用 Cloudflare 全家桶搭了个云端个人电脑。

Cloudflare 具体怎么用的:
🗂️ Durable Objects + R2 → 每个用户的虚拟文件系统
🔁 Workflows → 托管 agent 的持久化运行循环
💻 Sandbox → 给 AI 助手一台真实 Linux 主机,直接挂载用户文件系统
📬 Queues → 接 Telegram / Slack 的 webhook
🔍 AI Gateway → 统一监控所有模型推理

最妙的是靠 Durable Objects 天然做到了多租户隔离——整个系统里没有一行 WHERE user_id,每个用户的计算和存储本身就是边缘上独立的对象。

用作者的话说:感觉就像在用自己的本地电脑。体验链接见评论区。你也可以选择自己搭一个。
