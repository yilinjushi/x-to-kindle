一张图看懂：怎么让 Claude 记住经验、越用越顺

很多人用 Claude，一上来就是直接提需求、直接开干，结果短期还行，任务一多就开始乱：

同样的规则反复说，同样的经验留不下来，前面刚总结的方法，后面又得重新喂一遍

问题不在提示词，更大的问题，是你没有给 Claude 一个可以复用经验的外置记忆系统。

这位AI大佬 @PawelHuryn 教你怎么解决：

把一套工作规则写进 CLAUDE.md，再配合 knowledge/ 文件夹，让 Claude 在每次任务前先回顾规则，在任务后沉淀经验

先准备一个 CLAUDE.md，并按领域建立对应的知识文件夹，例如：

/knowledge/pricing/ knowledge.md hypotheses.md rules.md

维护一个 /knowledge/INDEX.md，用来指向各个领域文件夹

然后把这段内容复制到 CLAUDE.md 里：

开始新任务前：

  • 回顾该领域已有的 rules 和 hypotheses
  • 默认优先应用已确认的 rules
  • 检查本次任务是否可以验证某个 hypothesis

每个任务结束后：

  • 提炼本次任务中的新洞见
  • 将洞见存入对应的领域文件夹，例如： /knowledge/pricing/ knowledge.md （事实与模式） hypotheses.md （仍需更多数据验证） rules.md （已确认，默认应用）

知识库维护规则：

  • 维护 /knowledge/INDEX.md，作为各领域文件夹的总索引
  • 当一个 hypothesis 被确认 5 次以上时，将其升级为 rule
  • 当一个 rule 被新数据推翻时，将其降级回 hypothesis
  • 保持规则简洁、明确、可执行

这样做的作用是：

第一，减少重复沟通不用每次都从零解释背景和要求

第二，让经验能积累。做完一次任务，不是聊完就没了，而是能沉淀进知识库里，后面继续复用

第三，让 Claude 越用越顺。它不是单次对话工具，而是开始基于你过去整理过的结构做事

以上的所有内容都可以让claude code 帮你完成！

Most people's CLAUDE.md is static instructions. Mine compounds.
