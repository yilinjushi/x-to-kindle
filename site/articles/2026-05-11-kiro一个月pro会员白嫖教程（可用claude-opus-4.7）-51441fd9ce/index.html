Kiro一个月PRO会员白嫖教程（可用Claude Opus 4.7）

Kiro 是什么？

Kiro 是亚马逊 AWS 推出的一款 AI 编程工具，一款很好用的vibecoding软件

最关键的是，它内置了 Claude 系列的所有模型，包括现在最新的 Claude Opus 4.7，还有别的一堆模型

官网下载地址：https://kiro.dev/downloads/

这次的活动是什么？

Kiro 现在在做拉新活动，新注册账号可以直接获得一个月的 Kiro Pro 会员，价值 20 美元。

一个月 Pro 会员能干嘛？

  • 爽用 Claude 各个模型，包括 Claude Opus 4.7

  • 1000 积分用量，对个人开发者来说够用了

  • 完整的 AI 编程功能全开放

整个流程走下来好简单，下面手摸手教学

准备材料

在开始之前，先把这两样东西准备好：

  1. 一个没注册过 Kiro 的 Gmail 账号或 Github 账号必须是新账号，注册过的不行。 如果你的 Google 账号已经注册过 Kiro，可以试试用 Google 注册一个 Github，再用这个 Github 去注册 Kiro（套娃了属于是）。

  2. 一张信用卡国内信用卡可以用，Visa、万事达都行。 嫌麻烦的话，咸鱼上 2 块钱能买到一张 0 元虚拟卡，实测可用，省时省力。

操作步骤

第一步：注册登录

打开 Kiro 网站：https://app.kiro.dev/signin

选择 Google 登录，或者 Github 登录，进去就行。

第二步：选择套餐

登录后会直接跳到订阅界面。

这里有两个选项：

选项 A：选 $20 这一档拉新活动直接抵扣 $20，实付 $0，获得一个月 Pro 会员。

选项 B：选 $40 这一档（更划算）Kiro 活动最多减 $20，加上新账号首充优惠，最终只需要 $9.1，可以获得 2 倍 Pro 用量。

点击对应档位的「Upgrade to Pro」按钮。

进入支付页面后，看左边的金额，如果显示 $0.00，说明优惠已经生效，是对的。

第三步：填写信用卡信息

填入信用卡信息，点击订阅。

等个几分钟，刷新一下订阅界面，看到 1000 积分，就说明订阅成功了。

⚠️ 记得取消自动续费订阅成功后，点右上角的「Manage plan」进入订阅管理，把连续订阅关掉，别忘了这一步。

到此为止 可以去畅用claude了！kiro本身也是很好用的！
