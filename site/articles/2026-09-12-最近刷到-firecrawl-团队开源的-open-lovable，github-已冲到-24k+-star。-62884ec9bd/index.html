最近刷到 Firecrawl 团队开源的 Open Lovable，GitHub 已冲到 24k+ Star。

用法几乎零门槛：把你想“复刻”的网站链接丢进去，几秒内生成一个高度还原的 React 版本，布局、样式、交互尽量贴近原站，拿来二次开发也顺手。

GitHub： http:// github.com/mendableai/ope n-lovable …

亮点速览：

  • 一键把任意网站“克隆”为 React 应用，页面再复杂也能顶住
  • 可接入 OpenAI、Anthropic、Gemini、Grok 等多模型，按需切换不折腾
  • 基于 Firecrawl 抓取页面结构，还原更稳、更一致
  • 支持本地调试与部署，生成同时预览，所见即所得
  • 集成 E2B 沙盒，运行与测试更安全，也更省心

MIT 协议，完全开源：拉到本地，配好相关 API key，直接开跑。
