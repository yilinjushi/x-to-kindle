Codex 卡在 5/5 重连，别再一遍遍点重试了。

很多时候不是服务挂了，而是你的代理只管了浏览器，Codex 还在“裸连”。

浏览器通常会跟随系统代理，但 Codex 本地进程不一定会自动读取。所以你明明开着代理、网页也能正常访问 OpenAI，Codex 依然可能反复重连。

解决方法，Mac 和 Windows 基本一样：

Mac：

按 Command + Shift + . 显示隐藏文件 打开 /Users/你的用户名/.codex/ 新建一个名为 .env 的文件

Windows：

打开 C:\Users\你的用户名.codex 新建 .env 文件，注意别保存成 .env.txt

写入：

HTTP_PROXY="http://127.0.0.1:代理端口" HTTPS_PROXY="http://127.0.0.1:代理端口" NO_PROXY="localhost,127.0.0.1,::1"

代理端口去自己的代理软件里看。我用的是 Clash，端口为 7897。

保存后彻底退出 Codex，不是只关窗口，然后重新打开。

5/5 不一定全是代理导致，但如果浏览器正常、Codex 还在反复重连，先检查这个，通常最省时间。
