开源了39种风格视频库后，我学会了如何用Opus5.5稳定出片

一、我做了很多尝试，整理成了一个开源库

最近一直沉迷用 Claude Opus 5.5 做视频，前后做了 100 多支，挑了 39 支，每支代表一种风格：水墨、皮影、油画厚涂、80 年代赛璐璐、像素 RPG、60 年代间谍片头、纸片立体书……

这些片子没有用任何视频生成模型，也没有用素材库画面。每一帧都是 Opus5.5 写代码画出来的：Canvas 和 WebGL 页面逐帧渲染，配乐用免费采样库写原创曲子，配音用本地 TTS，最后由它自己混音、校对、出片。

做到后来我发现，片子好不好、稳不稳，关键不在提示词写得多华丽，而在两件事：

  • agent 手里有没有一套成熟的方法：怎么讲故事、怎么定节奏、怎么拍镜头、怎么配声音、怎么自检。

  • 你给它的需求有没有说到点上。

第一件事我已经做完了，我的开源库 Lemo-opuscar 整理成了三份文档：

  • DIRECTOR.md：导演方法（故事、声音、节奏、镜头、表演、自检）

  • TECHNIQUE.md：技术方法（逐帧渲染、配音、配乐、混音、审片）

  • styles/<风格>/STYLE.md：39 种风格各自长什么样、听起来什么样，以及样片是怎么做出来的

用法很简单：

git clone https://github.com/lemomo-ai/lemo-opuscar.git cd lemo-opuscar claude

然后直接跟 agent 说：“用水彩风格做一支 45 秒的片子，讲我家经营的咖啡园。”它会自己读这三份文档，像一个小工作室一样开工，中间停下来找你确认两次：一次看故事和分镜，一次看画面。

仓库：https://github.com/lemomo-ai/lemo-opuscar

在线图鉴（39 支片都能直接看）：https://lemomo-ai.github.io/lemo-opuscar/

剩下的就是第二件事：需求怎么说。

二、需求怎么说：你说内容，编排交给 agent

一个原则：你负责“拍什么”，agent 负责“怎么拍”。你不需要懂分镜、BPM、景别，但下面六件事说清楚了，出片会稳很多。

  1. 主题：拍什么、给谁看、多长

一句话说清楚。“做一个视频”太空，“做一支 40 秒的片子，给新用户介绍我们 app 的离线模式”就够了。

  • 时长，默认 30–60 秒。短比长稳，第一支建议 30–45 秒。

  • 比例，默认横屏 16:9。要发抖音、小红书就说“竖屏 9:16”。

  • 语言，就用你说话的语言，自动烧录字幕。

  1. 故事：有就给，没有就给方向

有真实的故事最好：你的经历、品牌的来历、一个梗、一个数据。事实部分一定要你给（名字、数字、必须出现的产品和标志），agent 编的事实不可靠。

没有故事也没关系，给一个方向就行，比如“温暖一点，结尾有反转”。它会按“一个主体、一个目标、一次转折”的结构自己编，开场 3 秒抓人，结尾首尾呼应。

  1. 节奏：快还是慢

这一条最容易被忽略，但它决定了整支片子的骨架。在我们的流程里，音乐网格先于动画：agent 先写 cue map（速度、小节、每个卡点落在哪一拍），画面再卡到网格上。所以你说的快慢，会直接变成：

  • 音乐：快闪卡点可能到 140 BPM 以上，抒情片在 70–90 BPM。

  • 剪辑密度：快片一拍一个动作，慢片一个长镜头走到底。

  • 速度变化：好片子不是匀速的。可以直接说“前面慢，中间越来越快，高潮前停一下，结尾留白”。

还可以说有没有旁白、什么声线：“温暖的女声旁白”“不要旁白，纯音乐”“像默片一样只用字幕卡”。

  1. 导演能力：镜头、编排、表演、声音

这部分是 agent 的活，DIRECTOR.md 里写得很细：

  • 镜头：每个镜头都有理由，全片至少 4 种运镜，有一个让人记住的签名镜头（一镜到底、尺度揭示、用媒介本身做转场）。

  • 编排：转场在风格里设计（水墨用墨滴洇开，立体书用翻页，剪纸用刀刻），不用默认的淡入淡出。

  • 表演：每个动作有预备、动作、跟随；角色有情绪变化。

  • 声音：画面上每个动作都有声音，至少两处真正的静音，不用万能的“钢琴 + 弦乐”。

你能做的最有用的一件事是给一个对标：“节奏参考 Edgar Wright 的剪辑”“像 60 年代 007 的片头”。对标只学语法（构图、节奏、镜头、配乐结构），不抄角色和画面。在我所有的经验里，对标对质量的提升比任何一条规则都大。

  1. 其他素材：代码画不了的，可以补

我这 39 支是纯代码做的，但你的片子不必这么“洁癖”。可以补充：

  • 生图工具：出角色设定、贴图、背景参考，让 agent 照着画或直接用作图层。

  • 3D 模型生成工具：生成 glb 模型，放进 three.js 场景里打光、景深、运镜。

  • 你自己的东西：照片、logo、产品截图、一段录音、品牌字体。

放进一个文件夹，告诉 agent 路径就行。唯一要注意的是版权：库里只用 CC0、CC BY、OFL 的素材，每一条都写进 CREDITS。

  1. 审阅与检验：两个确认点 + 它自己的质检

agent 会停两次：

  • 故事和分镜：在这里改方向只要几分钟，全片渲完再改要几个小时。这一步请认真看。

  • 画面：它会渲 2–3 张风格帧（有角色的话还有角色设定表），并告诉你它最没把握的地方。

之后它会自己质检：每句配音用语音识别转写回来核对，响度到 −14 LUFS，检查黑帧，每 1–2 秒一帧拼缩略图总览，关键动作按 0.2 秒抽帧看。

成片出来，你只需要看，然后把反馈说具体：“第 12 秒摔倒太快，看不懂”，比“节奏不太对”好用十倍。我看片时最常挑的几类问题：主体太小、字幕没停够就切走、动作不连贯、有动作没声音。

万能模板

什么都不会的话，复制这个，填空就行：

用【风格名，比如 watercolor】风格做一支【30–60】秒的片子。 主题：【拍什么，给谁看】 故事：【有就写：谁、想要什么、发生了什么、结局。没有就写“你来编，要有一个转折”】 节奏：【快 / 慢 / 前慢后快】，【旁白：什么声线、什么语言；或者不要旁白】 对标：【一两部你喜欢的片子、片头、广告，学它的节奏或镜头】 素材：【我放在 assets/ 里的照片、logo、模型；必须出现的名字和数字】 画幅：【横屏 16:9 / 竖屏 9:16】 先给我看故事和分镜，再给我看画面，我确认后再做全片。

连风格都不知道选哪个，就说：

我想做一支关于【……】的片子，帮我从库里挑两三个合适的风格，说说各自怎么拍，其他你定。

提前说明：一支片子 agent 大约要干 30–60 分钟，token 用量不算高，3D的场景比2D的高出很多，默认用High档位效果就非常好。需要 Node 20+、Chrome、ffmpeg、Python 3.11+；配音模型、采样库这类大文件，用到时才会下载。

三、没有 Opus 5.5 怎么办

先说实话：这 39 支片都是我用 Opus 5.5 做的，风格也是按它调出来的，其他模型我没有系统测过，不保证能做出同样的效果。一支片子要连续写几千行代码、自己看图、自己听混音、自己返工，对模型的长程能力要求很高。

不过这套方法本身不绑定模型，三份文档都是普通的 Markdown，任何能读 AGENTS.md 的 agent（Codex、Cursor……）都能用。如果你用的是其他模型，我的建议是：

  • 从样片改，不要从零写。每个风格的 demo/ 里都有完整源码和 build.sh，sh tools/fetch.sh demo <风格> 取回配乐、字体这些输入，就能重建我们的样片。让 agent 在一个能跑的引擎上换故事、换内容，比从零搭稳得多。

  • 先挑“代码原生”的风格。排版、图形、数据类（瑞士排版、数据叙事、等距信息图、ASCII 终端）对模型最友好；角色动画和 3D 最难。

  • 缩短、减量。先做 20–30 秒、一个角色、4–6 个镜头。

  • 拆小步，多停几次。方案 → 风格帧 → 单个镜头 → 全片，每一步都让它渲出静帧给你看，别一口气跑到底。

  • 强模型当导演，普通模型干活。导演方案和分镜用最强的模型写，执行交给便宜的模型，审片再切回强模型。

  • 标准可以降，流程别省。声音、自检、两个确认点，这些和模型无关，照做就能少踩很多坑。

四、11 支片子，看看能做到什么程度

从 39 支里挑了 11 支，尽量覆盖不同类型。全部 39 支在图鉴里：https://lemomo-ai.github.io/lemo-opuscar/

01 Swiss Motion Graphics 瑞士动态排版 《Five Rules for a Poster》

内容：一张音乐会海报按瑞士设计的五条规则自己排版，第五条是只打破一条。风格：50–70 年代苏黎世海报的语言：白纸、黑字、黑条，全片只有一种红色。 手法：所有元素吸附网格，每次落位都踩在拍子上，像一声打击乐；唯一不守规矩的红色元素成了主角。结尾揭晓 7 列网格就是 7 个音、16 行就是 16 个八分音符，海报本身就是乐谱。 适合：品牌视觉、活动、设计教学。

02 Urban Sketch 钢笔淡彩 《Where the Wind Went》

内容：公园只是一张钢笔速写，风把草帽吹到哪里，哪里才有颜色。 风格：现场写生的速写本：一根细细的棕黑钢笔线，上面罩一层透明水彩，颜色和线稍微错开，纸边留白写手写笔记。 手法：线条按真实笔顺一笔笔画出来；颜色从一个源头带着水痕洇开，被颜色碰到的人物才开始动；最后拉远露出整页速写本，兼作片尾。 适合：城市旅行、建筑、生活方式品牌

03 Chinese Ink Wash 中国水墨 《The Swordsman and the River》

内容：侠客踏水过江，一剑断流。 风格：宣纸上的五色墨，没骨画法，六到八成画面是留白，唯一的红色是一方朱印。 手法：留白就是江水，一剑劈开露出纸白；墨滴洇开代替转场；高潮前全场静音，一笔飞白横扫整个画面。 适合：武侠、文化品牌、诗词。

04 Shadow Puppetry 皮影戏 《Hou Yi Shoots the Suns》

内容：十日炙烤大地，后羿张弓射日。 风格：幕布后一盏油灯，染色驴皮刻成的影人透着光，红绿赭像彩色玻璃一样发亮，关节铆钉清晰可见。 手法：每个太阳就是幕后的一盏灯，每射下一个，画面就真的暗一档；影人拿在手里微微发颤，腿和翎子随铆钉自由摆动；高潮后绕到幕后，露出灯、艺人的手和竹签。 适合：神话民俗、非遗、节日。

05 · 60s Spy Title Sequence 60 年代间谍片头 《The Velvet Cipher》

内容：虚构 1964 年间谍片的片头：追一把被偷的钥匙，几何碎片最后拼成片名。 风格：Saul Bass 时代的片头设计：平涂纸色、手剪边缘、剪影人物，字体就是画面结构。 手法：演职员表就是布景，主角躲在字母 I 后面、在单词之间跳车；图形匹配剪辑（车轮 → 轮盘 → 瞳孔 → 月亮 → 锁孔）卡在铜管上，越追切得越快；碎片沿开场的斜线飞回，拼成片名。 适合：片头、活动开场、预告片

06 Whiteboard Explainer 白板讲解 《Einstein in Your Pocket》

内容：手机怎么知道你在哪：GPS、原子钟，和相对论每天多出的 38 微秒。 风格：一块真实的白板，没有手：马克笔自己飘着写，墨水在落笔处积墨，还有擦不干净的旧笔迹。 手法：公式按笔顺一项项写出来，正好对上旁白说到的那个词；一台摄影机跟着笔走到底，不剪辑；两支笔同时写，对比地面和轨道上两个时钟；最后拉远，整块白板一次看全。 适合：知识科普、网课、产品原理。

07 Living Screencast 活体实机录屏 《Clawd Moves In》

内容：像素小人 Clawd 跳出终端、搬进 Claude 应用，在一镜到底的录屏里演示 Plan 模式、diff 评论和自检。风格：看起来像真实产品的录屏，但每个窗口、菜单、按钮都是用代码重画的；大方块像素的小人住在高清界面里，两种分辨率的反差就是风格。 手法：录屏软件式运镜，一镜到底推近、甩镜头；小人只站在真实界面元素的上沿，位置每帧从页面实测；它的每个动作都触发一次真实的界面变化，每次按键都显示在屏幕上。 适合：产品教程、功能发布、新手引导。

08 Pictogram Motion 象形运动图形 《Aichi-Nagoya 2026 — All 43 Sports》

内容：2026 亚运会 43 个大项，几何象形人卡着节拍快闪。 风格：赛事视觉系统：满屏的几何纹样网格，没有脸的象形人，巨大的粗体标题配日文副标题，每个章节一种颜色。 手法：150 BPM 太鼓电子配乐，70 张运动卡一拍一个动作；同一个速度里切出一拍两张的快板，多出一种快慢；最大的章节用一个横移长镜头拍完；最后所有图标拼成一面墙，收成一轮太阳。 适合：体育赛事、视觉识别、活动开场

09 HD-2D 《The Lampbearer》

内容：灯塔熄灭，孙女提着最后一簇火穿过夜林、爬上风暴悬崖。 风格：3D 微缩场景贴像素材质，2D 像素角色站在里面；冷蓝夜色对暖橙火光，强辉光、重暗角，再配一套精致的 RPG 界面。 手法：角色保持低帧率像素，摄影机、光、粒子、焦点每帧平滑运动；移轴景深让大场面显得小而珍贵；她提着的灯既是主光源也是情绪计量表，灯一亮影子就被拉长。 适合：游戏预告、奇幻、剧情短片。

10 Paper Pop-up 纸片立体书 《Pip's Paper Adventure》

内容：立体书在书桌上打开，小精灵 Pip 在纸片世界冒险，最后跳出书外。 风格：一帧里两个世界：照片级的真实书桌和台灯，桌上是一本立体书，里面是平涂、描边的剪纸卡通。 手法：真实灯光和微距景深照在纸片上，纸片投下剪影形状的影子；翻页就是转场，旧的纸片折下、新的弹起；故事里“又亮起的一盏灯”，最后揭晓是读者的台灯。 适合：儿童绘本、游戏预告、剧情短片。

12 Sci-Fi Sitcom Toon 科幻情景喜剧卡通 《Coffee Run》

内容：厌世天才开传送门只想买杯咖啡，却穿过越来越离谱的平行宇宙。 风格：给成年人看的 2D 电视动画：粗黑描边微微抖动，平涂色块配硬边阴影，大白眼小瞳孔，又恶心又可爱的外星生物，科幻装备被当成家里的破烂。 手法：用天大的科幻手段办一件鸡毛小事；每穿一次门，整个宇宙的配色、音乐动机、生物都换一套，全片只有传送门会发光。三段式越跳越快，最后一秒一个宇宙地连跳；每个离谱画面后面都跟一个反应特写，笑点在脸上，不在怪物身上；结尾两秒以上彻底静音，再抖包袱，呼应开头。 适合：喜剧、科技品牌、社媒短片。
