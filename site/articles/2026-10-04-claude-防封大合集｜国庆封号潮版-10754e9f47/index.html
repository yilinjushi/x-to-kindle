Claude 防封大合集｜国庆封号潮版

国庆这两天，Claude 封号封疯了。

用了两年的老号说没就没，刚充的 Max 说封就封，连写防封教程的博主自己都中招了。我前几天用云电脑注册的一个号，22 分钟就没了。

最近我发了一条防封短帖，十几万人看过，评论区和引用里又冒出来一大堆经验，有真管用的，也有越传越玄的。

这篇把它们全收拢到一起，按「网络 → 环境 → 注册 → 养号 → 内容 → 付款」的顺序排好，最后附辟谣和玄学区。

准备开号的，从头看一遍；已经被封过的，直接跳到第六节看止损。

一、网络：固定，比纯净重要

这是所有经验里共识最高的一条。

1、设备和出口 IP 固定。别今天洛杉矶、明天新加坡。很多人以为不换 VPN 就算固定，其实一个 VPN 里来回切节点，出口 IP 照样在变。

2、节点选一个就别动。地区先对一下 Anthropic 官方支持名单，美国、新加坡这类都可以。选定之后，长期就用这一个。

3、线路要稳。有人自建了 VPS，以为万事大吉，结果晚上丢包严重，IP 来回跳，第二天早上收到封号邮件。固定的前提是线路本身稳定。

4、别挤「全中国人都在用」的节点。机场的热门节点、热门 AI 平台的公共出口，用的人越多，越容易被一锅端。

5、查四个「偷跑口」。你以为开了代理就安全了，但流量可能从别的口子漏出去：

  • IPv6：很多梯子只接管 IPv4，IPv6 流量直接走国内。用不到就关掉。

  • DNS：IP 在国外，域名解析却走国内运营商，等于自报位置。

  • 终端：Claude Code 跑在终端里，走的是终端代理；浏览器走的是另一条线。两边出口 IP 必须一致。

  • WebRTC：浏览器可能绕过代理暴露真实 IP。懂的处理一下，不懂的别乱改。

6、IP 查一次就够。确认没问题之后，别天天上各种「纯净度检测」网站反复测，没意义。

二、设备和环境：一个号一个环境

7、被封过的浏览器，别再登新号。浏览器环境很可能已经被记住了，换号不换环境，等于换个马甲继续被认出来。

8、一个号固定一个浏览器环境。别一会儿 Chrome、一会儿 Safari、一会儿又换台电脑交替登。

9、自动化工具也连同一个环境。用 browser-use、Playwright 这类工具的，别另起一套全新的浏览器环境去登 Claude。

10、登录的端越少越好。主力用 Claude Code，网页只在付款时上一下，App 和浏览器插件能不装就不装。端越多，暴露的信息越多。

11、定期看一眼 Active sessions。Settings → Account 里能看到所有登录设备，有不认识的先踢掉。

12、账号和 Key 自己用。分给好几个人用，多地同时登录，是最显眼的异常。

13、定位权限用不到就关。缓存出问题再清，不用天天清。

三、注册：开局别埋雷

14、用自己长期在用的主流邮箱。邮箱自己保管，验证码别给任何人。

15、最近别用云电脑、AI 平台代注册。这类平台注册的人太多，出口都是同一批 IP，风控已经盯上了。我那个 22 分钟就没了的号，就是这么注册的。

16、弹 Persona 验证，就用真实证件。官方要求身份验证的时候，用自己的护照、驾照这类真实证件过，别找人代验。

四、养号节奏：像个正常新用户

17、Free → Pro → Max，一级一级升。新号 + 新卡 + 直接 20x，是风控眼里最显眼的样本。正常人都是用着用着发现不够，才往上加。

18、新号别一上来就把额度用光。有人上午注册、只在网页用了一次，额度短时间耗完，下午就被封了。

19、每周留点余量。有老号用户的习惯是每周用量压在 60% 以下，几乎没出过事。别天天顶格蹬。

20、闲置号也不安全。长时间不用、突然登录、突然猛用，同样可能触发检查。

五、内容：你用它干什么，也算风控

很多人只盯着网络，忽略了这一节。

21、它不愿意干的活，别硬让它干。反编译、擦边内容研究这类任务，会直接撞上 usage policy。有人两个号同一天被封，一个提示登录国家不对，另一个就是违反使用政策。

22、正经活留主号。乱七八糟的测试，别拿主号试。

六、付款和止损：先想好被封怎么办

23、官网刷卡：被封不退款。Anthropic 条款里写明了，违规被封，一律不退。

24、App Store / Google Play 订阅：至少有个兜底。被封后可以找苹果、谷歌申请退款。最近也不是百分百能退，但总比官网强。Google Play 还能绑国内信用卡。

25、卡、账单地址、IP，三个地区对得上。卡的归属地、填的账单地址、登录 IP 的地区，差得越远越危险。

26、付款成功就固定这张卡。别频繁换绑。

27、⚠️ 被封后第一时间关掉自动续订。这一条最容易被忽略。封号和扣款各走各的，号没了，下个月照样扣钱。

28、申诉可以试，但别抱太大希望。复核维持原判是常态。

七、辟谣：这几样别再花冤枉钱

  • 家宽 IP：跨境电商带起来的风气，Claude 用不着。大厂程序员走公司机房 IP 照样天天用，关键是稳定。

  • 线路连坐：没见过同事被封、全公司跟着封的。

  • 改美国时区、系统改英文、对话全用英文：作用不大。中文系统 + 上海时区跑 Claude Code 的大有人在。

  • 老谷歌号、美国谷歌号：没依据，谷歌不会把你的账号年龄告诉 Anthropic。

八、玄学区：信不信由你

这几条没法验证，但传得很广，放这里给大家参考。

账号价值说Claude 会给账号算「价值」。天天写代码、写文案的号最容易被封，常问前沿研究、数学、论文的号很少出事。照这个说法，新号第一件事该是拿公开行业报告去问它，把自己养成「研究员号」。你的对话越有训练价值，它越舍不得封你。

20x 强制检测说升 20x 会触发一次强制检查，普通号只是随机抽查。所以「开 20x 就被封」，其实是「开 20x 必被查」。

GitHub 扫描说连了 GitHub 的云端会话，可能会扫你的仓库和活动来判断你在哪。不放心就先别连。

九、最后说句实话

评论区有一条特别扎心：没有哪个方法确定防封，全看运气。

也确实有反例：中文系统、中国时区、上来就开 Max，一周了还活着。

所以上面这 28 条，降低的是概率，不是保险。

真正管用的是最后一条：核心工作流别单押一个账号，留条后路。号可以被封，活不能停。
