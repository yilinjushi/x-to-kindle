最近折腾出一套很牛逼的组合，我认为是国内玩 Claude Code 的极佳玩法，懂的来

Grok bot + Orca + Tailscale + Claude Code

  1. 在 Grok bot 的美国云主机上注册 Claude，然后安装 Claude Code（如果担心 Grok bot 的稳定性，建议换成 VPS）

  2. 把云主机上安装 Orca，并配置成 Orca 服务器 @orca_build

  3. 在云主机上安装 Tailscale，并用 Tailscale 组网把所有设备加进来

  4. Tailscale 网内任何一台机器打开 Orca 客户端连上云主机的 Orca，就能直接用 Claude Code，7 * 24 小时在线
