this folder is your studio, and every video you make from here on starts inside it

one heads-up, Remotion is a docs page and you can't clone it, so we install it with the skills in the next step

you don't need to clone these one by one either, i already did it and turned the whole thing into a prompt, so Claude handles it for you

copy this and paste it into Claude Code:

Inside this folder, create a subfolder called "repos".

Clone these repos into it: https://github.com/JohnHeibel/PDoomVideo https://github.com/JohnHeibel/ClaudeAnimationBase https://github.com/buildwithhanif/claude-animation-skill https://github.com/heygen-com/hyperframes https://github.com/WinterArc21/Battle-of-Austerlitz-Film https://github.com/guanmo-ai/awesome-ai-motion https://github.com/athemeroy/awesome-opus-5-5-videos

For HyperFrames, skip the large test videos (use GIT_LFS_SKIP_SMUDGE=1).

Before cloning, check if Node.js 22+, git and ffmpeg are installed. If anything is missing, install it.

When done, list every repo with one line on what it's for.

install the skills

skills are instruction packs, and they're the part that stops Claude from guessing

the repos show Claude what good output looks like, while the skills hand it the working rules for each framework, so it builds the way the framework expects

paste these into your terminal, one at a time:

npx skills add remotion-dev/skills claude plugin marketplace add heygen-com/hyperframes claude plugin install hyperframes@hyperframes claude plugin marketplace add buildwithhanif/claude-animation-skill claude plugin install claude-animation@claude-animation-skill
