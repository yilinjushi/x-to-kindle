AI 短剧焚决：用 Claude Opus 5.5 做短剧的一手实战教程

想用 AI，把脑子里的故事做成自己的第一部短剧？ 这份 AI 短剧焚决，就从一个我真实做过的项目开始，带你拆解从想法到成片的每一步。

我做《雨停之前》第一集，投入了约 3500 元的生成相关费用，最后做出约 4 分 24 秒的成片。第一次做，没有经验，拍法、人物、声音和剪辑都在边摸索、边修改、边学。这笔钱里，也有我为成长交的学费。

我把这些一手经验整理成这份教程：怎样让 Claude 组织制作，怎样接入视频模型，怎样用 480p 少花钱试片，怎样生成 20 多秒的场景，以及那些花过钱才弄明白的坑。文末还有一份可直接复制的需求模板。

最近，@antrofrog_ 的 《Englishman in New York》 爆火，截至写稿时已超过 2800 万次浏览。看到这样的作品，再结合自己的实践，我越来越确定：想做短剧、动漫的人，都可以借助 AI，从第一个短场景开始。

不会画画、不熟悉剪辑，也可以边做边学。先用 480p 做一小段、验证想法，入门的制作成本已经可以压得很低。我愿意把自己的摸索摊开讲，也希望你能从更小、更便宜的试片开始。

但想把作品做好，仍然要学习剧情、情绪、审美、音乐节奏和观众心理。人物为什么这样行动？音乐什么时候进入、什么时候停？观众为什么愿意继续看？这些判断，需要在创作中慢慢练出来。

这也是我目前暂停更新《雨停之前》的原因：制作流程已经跑通，我对创作的理解还要继续提高。等这些认知积累得更扎实，再在合适的时候继续。眼下，先把这套能动手的方法分享给你。

原作用了 Midjourney 角色设计、Seedance 动画和 Krea 平台。下面分享的是我自己的 Claude Code 协作流程；画面同样需要视频模型生成。

先说我做的这个故事： 一封写着自己名字的信，落款却是自己出生前的一年。 窗外的街道，正在一点点变回那个年代。 推开门，又遇见一个和自己长得一样的人。

这是《雨停之前》第一集，定版约 4 分 24 秒。

做这部剧时，最值得讲的，是怎么把一个故事变成一组能接起来的画面：同一个人、同一家店、同一场雨，观众能一路跟着她走下去。

下面用 Claude Code＋Opus 5.5，拆解这套制作流程。想表达什么、要什么氛围、哪些内容留下，由我决定；Claude 按要求组织剧本、调用工具、完成后期。

01｜先把工具接好，再开始拍

Opus 5.5 是在 Claude Code 里使用的模型。Claude Code 可以处理项目文件、编写和运行脚本；真正生成视频画面的，是接入的视频模型。

这次项目的主要分工：

  • Claude Code：剧本、分镜、生成任务和后期流程。

  • Seedance 2.5：生成视频及同期声。

  • Gemini：辅助制作场景设定图、关键画面，并辅助检查。

  • GPT Astra：帮我审片、梳理问题和汇总反馈，由我确认后再交给 Claude。

  • Lyria：生成配乐。

  • 本地剪辑工具：字幕、画面修正、声音和成片合成，由 Claude 编写脚本调用。

上手按这个顺序： ① 按 Claude Code 官方快速入门安装、登录。新建一个短剧项目文件夹，在这个文件夹启动 Claude Code。 ② 输入 /model，选择账户可用的 Opus 5.5；没有该选项时，先检查客户端版本和账户权限。 ③ 在火山方舟开通可用的视频模型，按官方说明配置 API；图片和音乐接口按需要配置。密钥放在本地配置里，不写进剧本或分享材料。 ④ 先让 Claude 检查连接和工具，再做一条短样片。

Claude 的订阅不包含其他平台的生成费用。先设好本轮预算，确认一次生成能成功，再批量做。项目当时使用的具体模型版本，也不必机械照搬为今天的最新版本。

02｜把“我要一部悬疑剧”写成能验收的需求

《雨停之前》的起点，是离开小城前的一个雨夜：女孩进了旧书店，捡到一封时间对不上的信。

围绕这个故事，我给过一条明确要求：

“每一集不断解开一部分疑问，然后再埋入后面的。”

这句话落到第一集，就是：让观众看到异常，跟着主角确认异常，最后遇见一个更大的疑问。

你可以先把五件事告诉 Claude：谁在看、主角想做什么、什么阻止了她、整集是什么情绪、结尾要让观众追问什么。然后要求它输出一页故事方案，先别生成画面。

请先给我：一句话故事、主角目标、主要冲突、开场异常、结尾疑问。再标出哪些信息靠画面表达，哪些必须用台词。暂时不要生成视频。

验收时看一件事：拿掉“悬疑、电影感、高级”这些形容词，这个故事本身还想不想看？

03｜先把剧本、人物和分镜对齐，再花钱生成

故事通过后，让 Claude 建三份材料：

  • 人物卡：外形、服装、说话方式、当前处境。

  • 场景卡：门、窗、柜台、灯和关键道具的位置。

  • 分场表：每场发生什么、人物怎么移动、观众获得什么信息。

先选定你认可的人物样片，再把符合平台当前规则的原始素材作为后续参考。不要每生成一版，就把新一版继续当唯一标准；这样人物可能越传越不像。声音也要单独检查，脸相似不代表声线一致。

场景卡要写到具体位置。比如：柜台后是挂钟和信架，窗在另一侧；主角从柜台走到窗边，需要交代这个移动。

《雨停之前》有过设定图里带窗、文字却说那里没有窗的情况。图和文字互相打架，生成结果就难稳定。先让 Claude 对照两者，把矛盾清掉。

剧本和分镜一定要先对齐。剧本说明这一场为什么存在、观众要知道什么；分镜把它落实成谁在什么位置、做什么动作、出现什么画面和声音。两份材料没有对上，就先别开拍。

下面两个示例按《雨停之前》的实际修改整理，用来说明怎么表达需求，不是原始对话或逐秒分镜。

示例一：主角发现书店剧情目标：让观众跟着主角一起发现异常，产生“这家店为什么亮着灯”的疑问。分镜顺序：她撑伞沿街走 → 书店暖光随她靠近进入画面 → 她停步观察橱窗与铜铃 → 接靠伞、推门进店。声音：以雨声和脚步为主，不加解释性旁白。验收：人物没有被空街镜头弄丢；进门前后的伞、位置和动作接得上。

示例二：第一次打开信剧情目标：让观众听见信里的异常信息，同时看见人物反应。分镜顺序：展开信，纸背朝镜头 → 低声念“林晚……雨停之前，别走” → 放下信、抬眼 → 接她去找店主。验收：这次读信不直接展示正文；后面需要展示信时，用确认好的同一份文字。冷开场露信属于另一个叙事位置，不能误删。

把这两种表达交给 Claude，它才知道“悬疑”具体落在哪个画面上。拍前再让 GPT 看剧本和分镜，找人物移动缺口、重复信息、图文矛盾；我确认后，Claude 再把修改合进同一版材料。

请先核对剧本、分镜和设定图：每场的剧情目标是什么？镜头是否真的表达出来？人物进出、站位、道具、光线和声音能否连续？哪些台词重复了画面信息？哪些关键动作还没有镜头？把矛盾和待决定项列出来，先对齐文本，不要开始付费生成。

04｜先试一段完整的戏，再扩成一集

第一集有一版把 53 个镜头分别生成。问题集中出现在连接处：柜台位置变了、道具换样了、人物移动没交代，同一个动作还可能重复。

后来改成把同一空间里的一小段连续行动放在一起生成。例如：发现信、拿起信、读完后抬头。

这种做法减少了反复重建场景的机会，但仍然需要检查连续性。

这里有个很实用的能力：接入的 Seedance 2.5 可以一次生成 20 多秒的视频，官方文档目前列出的上限是 30 秒。这个时长能力属于视频模型，由 Claude 组织调用。能力说明

这样，一小段有起承转合的动作就有机会放进同一次生成里。项目里用过 15—30 秒的场景段落；也别为了凑满 30 秒，把太多动作和台词塞进去。

我的建议是先用 480p，把人物、动作、空间和节奏试顺。1080p 一旦反复生成，成本会明显增加；第一集 V6 的试拍、逐镜生成和重拍累计约 2564 元，就是我在这个阶段交的学费。

480p 有自己的限制：远景里人脸太小，表情就不容易看清。关键情绪和台词可以先用合适的近景验证。别把低清造成的模糊，直接当成换了一个人，也别指望转成高清就能自动修好人物漂移、穿帮或剧情问题。

Seedance 2.5 有样片模式：先生成 480p Draft，满意后，可以用这条样片的有效任务编号生成 1080p 正式视频。它会复用关键生成条件，不是随便拿一段 480p MP4 上传就能调用的功能。

这一步有四个细节：

  • 样片与正式版分别收费。先试片省的是反复试错的费用，高清生成仍要另外付费。

  • 样片任务编号有有效期，要让 Claude 记录编号、创建时间和当前转换期限。本地存了视频，也不能代替有效的任务编号。

  • 报价要包含参考视频等输入的计费因素，不能只按输出片长猜价格。

  • 第一次先转一条关键片段。转高清后重新看脸、表演、口型和声音；不要默认每个细节都和样片一模一样。样片模式与计费说明

这一轮先只生成 480p 样片，保留原片和样片任务编号。我确认人物、动作、台词、空间和节奏后，再单独报价一条 1080p 正式版。先确认任务编号仍有效，说明参考素材和正式生成各自的费用。转完后与样片逐项对比，不覆盖样片，也不直接批量转全片。

我的第一集最终直接采用了 480p，没有再转成 1080p。是否升级，按作品的实际呈现需要来决定。

先只做“发现信到抬头”这一段，使用 480p 样片。说明人物站在哪里、道具在哪里、动作顺序、台词和声音。给出预计费用，确认预算后生成样片。通过后再扩展下一场。

看样片时，连续看三遍：第一遍看人物，第二遍看空间和动作，第三遍只听声音。发现问题就定位到这一段，别急着把整集都生成。

05｜把难点单独拆出来：变化、文字、悬疑节奏

第一集的重要画面，是窗外的街变回 1995 年。

实际做法是先准备变化前后的两张窗景，把窗框位置对齐，再用它们约束过渡。两张图里连窗棂数量都要一致，否则年代变化很容易变成整扇窗一起变形。

信上的字也单独处理。这次生成的文字不能稳定符合剧本，所以先让纸面保持空白，再把确认好的字放到画面里。开头和后面展示同一封信，要用同一份文字素材。

还有一个很重要的取舍：少解释。读信时先给反应，重要信息在合适的位置露出来。片尾停在沈雨的自我介绍和“你呢？”，把身份疑问留下。

让 Claude 做完分场后，再检查一遍：有没有同一个信息说了两次？有没有表情已经表达出来，台词还要解释一遍？

06｜剪辑时，把画面、台词和音乐当成一整段看

片段齐了，让 Claude 先出粗剪，保留每条素材和对应的剪辑位置。

这一步重点看四件事：

  • 动作：上一段伸手，下一段有没有又伸一次？

  • 台词：有没有被切掉最后几个字？字幕能不能读完？

  • 环境声：画面里的门没动，声音里却突然响了一声？

  • 配乐：人物开口时是否太响？换镜头时是否突然断掉？

《雨停之前》的音乐，是跟着情节走的：异常出现时进入，窗外变化时推进，抵达旧街后展开，再随着人物进门收住。

即便提示词写了“纯器乐”，生成结果也可能混入像人声的声音。模型辅助检查能提供线索，最后仍要自己听实际成片。字幕也要对着实际说话时间校正。

07｜反复改不满意时，把审片和反馈整理成一套流程

前面调整时，我经常觉得改完还是不对，但只说“效果不好”“再优化一下”，很难让 Claude 抓住我要改的地方。后来，我把 GPT Astra 审片、自己确认、集中反馈、Claude 修改这套流程固定下来。

具体这样做： ① 把同一版成片、对应剧本和分镜交给 GPT Astra，让它先找问题。 ② 我回看片段，确认哪些问题确实成立，也把自己发现的问题、不舒服的地方和疑问补给它。 ③ 让 GPT 把两边意见合成一份清单，去掉重复、处理矛盾，写清位置、问题和想要的效果。 ④ 把这份清单交给 Claude，让它说明怎么改；能剪辑或后期解决的先解决，确实缺画面才补拍。 ⑤ 修改后，我和 GPT 按同一份清单复核新版，确认问题是否解决，有没有带来新的问题。

清单要分清三类：明确的穿帮、需要取舍的审美建议、还没证实的疑点。GPT 提了意见，我仍然要判断；Claude 也可以提出更合适的改法，并说明理由。

一个真实例子是“人物从柜台到了窗边，移动没交代清楚”。整理后的修改目标是：让观众知道店主一直在柜台后，林晚听到报时后才穿过书架走向窗边。Claude 围绕这个目标调整和补镜，比一句“衔接自然一点”具体得多。

给 GPT 的审片需求示例：请检查这版成片，并与对应剧本、分镜对照。按“成片时间位置 → 看到的问题 → 对观众理解的影响 → 修改建议”列清单。我补充的观察和疑问是：[填写]。请合并重复项，区分已确认问题、审美建议和待确认疑点。先形成一份统一反馈，不直接替我决定所有取舍。如果只能检查抽帧，或无法听到音轨，请明确写出来，不把没检查到的内容当作通过。

声音尤其要我自己听。项目里就有“像吟唱”的疑点，模型判断前后不一致，最后需要把实际片段和声音来源拆开，由我确认。审片助手能帮助定位，实际听感不能靠一句模型结论代替。

每轮意见都要标清对应哪一版。新版改完，保留旧版，并同步修改剧本、分镜和剪辑记录；删了台词、改了道具或顺序，下一轮仍照旧剧本生成，就会把问题带回来。

我还会把“这次错在哪里、为什么这样改”留下来。这样下一场开始前，Claude 就能读取已经确认的经验，减少反复解释同一个问题。

第一集最后定的是 480p、约 4 分 24 秒的版本。这里展示的是第一集的制作经验，目前这个系列已经暂停更新，原因放在文末讲。第一次上手，也可以先用一个短场景跑通全过程。

这集到底花了多少钱？

按项目记录粗算，第一集从试拍到定版，生成相关投入约 3500 元，包含多轮试错和重拍，不是一次成功的报价，也不代表做一集的最低成本。

几笔主要开销：

  • 第一版及早期重拍：约 83 元。

  • V3：约 67 元；V4、V5：合计估算约 249 元。

  • V6，1080p 逐镜生成及小样、重拍：约 2564 元。

  • V7，长片段样片测试：约 56 元。

  • V8，改成按场生成的 480p 版本：约 290 元。

  • V9、V10，继续补拍和调整：合计约 132 元。

现存视频账本合计约 3193 元，加上 V4、V5 的历史估算约 249 元，视频部分约 3442 元；再加设定图、配乐和辅助检查等费用，粗记约 3500 元。部分早期费用只能按工作记录估算，这里不含 Claude 订阅和人工时间。

第一集也是我学习这套方法的过程。很多后来才懂的事，当时要经过一次生成、一次看片、一次修改，才真正明白。钱花出去以后，把问题和解决方法留下来，才算把试错变成了经验。后续制作就可以带着这些判断开始。

对比最明显的是 V6 和 V8。但不能拿 2564 元和 290 元直接算出“480p 省了多少倍”：两轮的拍法、试错次数和已有素材都不同。真正有用的经验是，把高频修改放在低成本样片阶段，等故事和连续性成立，再考虑高清。

省钱的顺序也很具体：先用剪辑解决，再看后期能不能修，最后才补拍。只补缺的段落，别因为一个镜头有问题就把整场重新生成。

这几种坑，开拍前就值得记下来

① 参考片越传越不像。新镜头再当下一条的参考，人物会逐渐偏离原样。回到最初认可的原始参考，脸和声音分别检查。

② 参考片把不该带的东西也带来了。哭相、背景里的窗、原来的台词，都可能影响新镜头。人物参考要看表情和背景，声音参考要说清只参考音色。

③ 单镜漂亮，连起来不成立。人突然换位置，窗变成墙，杯子换样。先把场景关系写清，再按一小段连续行动来生成。

④ 指定文字没写对。信上的年份和句子是剧情证据，这次靠后期放入确认好的文字，不能把“差不多”当通过。

⑤ 声音比画面更容易漏看。无台词镜头可能念出动作说明，雨声可能夹着开门声，纯器乐可能混入类似吟唱的声音。先分别听，再连同画面听完整片。

遇到这些问题时，把“哪里不对、希望变成什么”写清楚，让 Claude 先判断能否局部修复。反复换一句“再高级一点”，往往只会增加生成次数。

你可以直接复制这份需求开始

我要做一部原创短剧，先完成一个短场景，再决定是否扩成一集。

观众：[写给谁看]

主角与目标：[谁，想完成什么]

冲突：[什么阻止了她/他]

氛围：[给出具体场景、光线、声音和节奏]

开场异常：[发生了什么不寻常的事]

结尾疑问：[观众看完会追问什么]

画幅和目标时长：[按发布场景填写]

本轮预算：[填写金额，不确定的费用先说明]

请按顺序完成：

  1. 一页故事方案。等我确认后，整理人物卡、场景卡和分场表，再把剧本、分镜、设定图对齐。

  2. 检查本地工具、已配置接口与当前模型能力；缺什么就列出来，不要假装已经接通。

  3. 先设计一段能检验人物、空间和声音的 480p 样片，说明费用。需要 20 多秒时先确认所接视频模型支持该时长。

  4. 在确认的预算内生成，保存素材及样片任务编号。把样片和对应剧本、分镜交给审片助手；我确认问题并补充观察后，汇总为一份反馈，再修改和复核。需要1080p时另行确认报价和任务编号有效期。

  5. 完成粗剪、字幕和配乐，保留素材与修改记录。

  6. 交付可播放成片，以及后续能继续修改的项目。

每一步都列出需要我判断的具体事项。关键文字以我确认的版本为准；参考素材使用我有权使用且平台接受的内容。

最后，说说我为什么暂停更新

《雨停之前》目前已经暂停更新。做过这一轮以后，我认识到：工具能帮我把片子做出来，情绪、审美、剧情、音乐节奏和观众心理上的理解，还需要我继续提高。

看到《Englishman in New York》这样的作品，我更想学习的是它背后的创作判断：什么样的人物让人愿意看，情绪怎样建立，画面怎样选择，剧情怎样推进。这也是我接下来要补的功课。

能生成一段 30 秒的视频之后，接下来要决定的是，这 30 秒里该发生什么，哪里值得停一下，哪里应该留白。模型能提供很多版本，我需要有能力判断哪个版本值得留下。

所以，我先把已经跑通的流程、花过的钱和踩过的坑分享出来。后面会继续学习情绪表达、审美、叙事、音乐节奏和观众心理，等自己的理解提高一些，再在合适的时候继续这个系列。
