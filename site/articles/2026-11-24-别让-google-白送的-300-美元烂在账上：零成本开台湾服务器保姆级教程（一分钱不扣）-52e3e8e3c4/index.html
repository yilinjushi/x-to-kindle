别让 Google 白送的 300 美元烂在账上：零成本开台湾服务器保姆级教程（一分钱不扣）

最近不少朋友开了 Google AI Pro 或 Ultra 会员，每天只拿来刷 Gemini 和 Antigravity。

其实你把账上最值钱的一项隐藏福利漏掉了。

Google 每个月都在后台给你发 Google Cloud 赠金，还能叠加新用户的 300 美元免费试用金。

以 Ultra 5x 为例，第一个月手里直接有 340 美元可以花。

更良心的是，哪怕你下个月把会员退订了，已经发到账上的这笔赠金也不会被收回，照样活满整整 1 年。

昨晚我拿这 340 美元从零开了一台台湾原生服务器，全程点点鼠标就搞定了。

建好之后直接把权限丢给 Claude Code 自动运维，一行 Linux 命令都不用自己背。

我知道很多人一直不敢碰 Google Cloud，核心就怕一件事：绑了卡万一超支，睡醒被反薅几百刀。

先吃颗定心丸：只要你不主动去点升级成付费账号，试用期就算额度烧干也只会停机，绝不会扣你卡里一分钱。

丑话说在前面，Google 的赠金规则和价格变动很快。

本文基于 2026 年 11 月 21 日实测整理，操作时请以官方页面和控制台显示为准。

一、先算清楚你能领到多少钱，以及去哪领

你能拿到的钱一共分两笔，而且可以打进同一个结算账号里合着花。

第一笔是 Google AI 订阅自带的月度赠金，通过 Google Developer Program 按月发放：

  • Google AI Pro：每月 10 美元

  • Google AI Ultra 5x：每月 40 美元

  • Google AI Ultra 20x：每月 100 美元

第二笔是 Google Cloud 新用户免费试用金，一次性给 300 美元，有效期 90 天。

两笔加一块，像我手头这个 Ultra 5x 账号，第一个月直接握着 340 美元预算开工。

方式一：直接在 AI Studio 里一键领（最省事）

这个入口是 2026 年 11 月 13 日刚上线的，不用到处翻页面，三步就能走完：

  • 用付订阅费的那个 Google 账号登录 https://aistudio.google.com

  • 点开左侧导航栏弹出的未领取赠金提示，依次点击 Claim Google Cloud Credits 和 Redeem and Continue

  • 如果你之前没建过 Developer Program 资料或 Google Cloud 结算账号，系统会在这一步顺带帮你建好

  • 领完打开 https://aistudio.google.com/billing 就能随时查余额

方式二：去 Developer Program 权益页领

如果你在 AI Studio 没刷出入口，也可以走官方权益页通道：

  • 打开 https://me.developers.google.com/benefits

  • 选一个 Google Cloud 结算账号接收赠金，顺手勾选 Always use this billing account，以后每个月赠金就会自动打进这个户头

  • 如果页面给的是一串兑换码，复制后去 https://console.cloud.google.com/billing/redeem 粘贴兑换即可

两笔都弄完之后，打开 Cloud 控制台进入结算下面的赠金（Credits）页面，每一笔钱的起止时间都列得清清楚楚。

以我 11 月 21 日实测的账号为例，同一个结算账号里同时躺着两笔：

  • 300 美元试用金：2026-11-21 至 2027-02-20（90 天有效）

  • 40 美元 Ultra 赠金：2026-11-21 至 2027-11-21（12 个月有效）

可能卡在哪，两个地方要注意：

  • 订阅赠金只有主订阅人本人能领，拼家庭组的成员没资格

  • 赠金一旦打进某个结算账号就没法转走，浏览器登了多个谷歌号的一定先看准右上角头像再点

二、动手前必看的规则和红线（防反薅核心）

虽然两笔钱都在一个池子里，但它们的抵扣范围和过期脾气完全不同，动手前花一分钟把账看明白。

两笔赠金的四个关键差异

  • 有效期与发放节奏：300 美元试用金是一次性给完、90 天清零；订阅赠金按首次领取的月度周年日按月打款（比如 11 月 21 日领首笔，下一笔 12 月 21 日到账），每笔单独算 12 个月有效期，花不完会一直攒着

  • 抵扣 AI Studio 的 Gemini API：300 美元试用金不能抵扣，订阅赠金能抵扣

  • 抵扣 Vertex AI：2026 年 11 月 16 日及以后注册或升级的试用金已经不能抵扣，订阅赠金依然能抵扣

  • 开虚拟机服务器：两笔都能直接抵扣

必须记牢的避坑铁律

  • 绝对不要点激活或升级到付费账号：一旦点了升级，赠金扣完的下一秒就会直接刷你的银行卡

  • 退订会员不收回已发赠金：退订 Ultra 后只是下个月不再发新钱，已经进账的额度照样满 1 年才过期

  • 扣款先后顺序不透明：同一个结算账号有多笔赠金时，Google 官方没有公开说明优先扣哪一笔

  • 赠金不报销的项目：Spot 或抢占式实例、承诺使用折扣（CUD）、Marketplace 镜像、第三方商业许可证，以及部分特殊机型和 GPU

  • 试用期账号自带的硬限制：不能挂 GPU、不能用 Marketplace、不能申请提配额、不能开 Windows 服务器，并且严禁挖矿

三、340 美元怎么花最划算：选台湾还是选香港？

在 Google Cloud 开服务器，每个月的真实开销由机器配置 + 硬盘 + 公网 IPv4 + 出站流量四块组成。

  1. 各区域机器月租参考

数据来自价格站 gcloud-compute.com（台湾 e2-medium 已在控制台核对一致），按需月租如下：

  • 美国 us-central1：e2-small（2G）约 12.2 美元，e2-medium（4G）24.46 美元，e2-standard-2（8G）约 48.9 美元

  • 台湾 asia-east1：e2-small（2G）约 14.2 美元，e2-medium（4G）28.32 美元，e2-standard-2（8G）约 56.6 美元

  • 东京 asia-northeast1：e2-small（2G）约 15.7 美元，e2-medium（4G）31.38 美元，e2-standard-2（8G）约 62.8 美元

  • 香港 asia-east2：e2-small（2G）约 17.1 美元，e2-medium（4G）34.22 美元，e2-standard-2（8G）约 68.4 美元

除了机器月租，每月还有两笔固定底座费别漏算：

  • 公网 IPv4 地址：0.005 美元/小时，折合每月约 3.65 美元

  • 20 GB 平衡永久性磁盘：每月约 2 美元

  1. 网络层级：决定流量费贵不贵的核心开关

Google Cloud 的网络分两档，这一项直接决定了你的赠金能撑多久：

  • 高级层级（系统默认）：走 Google 自家全球骨干网，回大陆线路质量稳，但没有一分钱免费流量。发往亚洲（含香港）按 0.12 美元/GB 计费，发往中国大陆按 0.23 美元/GB 计费

  • 标准层级（需手动切）：走普通运营商公网，不支持 IPv6，回大陆线路通常不如高级层级，但每个区域每月白送 200 GB 免费流量（超出后美国区 0.085 美元/GB 起，亚洲区更贵）。如果你在两个不同区域各开一台标准层级机器，每月就有 400 GB 免费额度

  1. 为什么强烈建议选台湾，别无脑选香港

很多国内玩家买机器习惯手点香港，但在 Google Cloud 里，台湾几乎全方位碾压香港：

  • 同配置下台湾比香港便宜约 20%

  • 台湾在 Gemini、ChatGPT、Claude 三大主流 AI 的官方支持地区内，而香港全都不在。只要你想在服务器上跑 AI 工具或调接口，选台湾省掉一堆折腾

至于延迟表现跟各家本地宽带运营商有关，讲究的话可以先两地各开一台测完速，再把不顺手的那台删掉。

  1. 两套现成抄作业方案（按 340 美元跑 90 天算）

方案 A：高级层级求好线路，只开一台（最省心推荐）

因为高级层级没有免费流量，多开一台机器纯属多交一份固定底租，不如只养一台小机器，把大头预算留给流量。

如果按出站流量全部发往中国大陆（0.23 美元/GB）顶格估算：

  • 台湾 e2-medium（4G，主力推荐）：机器加 IP 加磁盘每月约 34 美元，3 个月固定开销约 102 美元，剩下 238 美元折合每月可用大陆流量约 345 GB

  • 台湾 e2-small（2G，省钱多跑流量）：每月固定开销约 20 美元，3 个月花 59 美元，剩下 281 美元折合每月可用大陆流量约 400 GB

  • 香港 e2-medium（4G，对照参考）：每月固定开销涨到约 40 美元，每月可用大陆流量缩水到约 320 GB

  • 台湾 e2-standard-2（8G，重度负载）：每月固定开销约 62 美元，每月可用大陆流量还剩约 220 GB

方案 B：标准层级求大流量，双区开两台

台湾开一台 e2-standard-2（约 62 美元/月），香港再搭一台 e2-small（约 23 美元/月）。

两台每月固定合计约 85 美元，3 个月花掉约 255 美元，同时拿满两个区域合计每月 400 GB 免费流量。

四、第一步：先设预算提醒（避开 90% 人踩的静默坑）

正式开机之前先把账单警报拉上，全程在 https://console.cloud.google.com 操作。

进控制台左侧的结算页面，点下方红框标出的预算和上限，再点右侧新建。

  1. 定义：选仅提醒，别碰支出上限

第一步保持勾选仅提醒（适用于所有服务），随便填个预算名称就点下一步。

千万别被下面的强制执行支出上限诱惑去勾选。

那个功能只支持 Cloud Run、Cloud Run Functions、Gemini API 和 Vertex AI。

而且每个预算只能盯单个项目里的一项服务，根本管不到虚拟机和流量费。

试用账号本来就不会扣卡，选仅提醒才能把所有服务全纳入监控。

  1. 范围：取消勾选全部节省项（重中之重）

切到范围这一步，时间范围选自定义范围，开始日期保留默认的年初不动，勾上无结束日期，项目和服务都保持全选。

最底下节省的费用那一栏，把节省计划和其他节省两个勾全部去掉。

可能卡在哪：这里藏着两个极隐蔽的坑，踩中一个预算提醒就形同虚设。

  • 绝不能勾选其他节省。试用金和订阅赠金在账单系统里全算作其他节省，一旦勾上，系统统计的就是抵扣完赠金后的自付净额，永远是 0，哪怕 340 美元快烧光了也不会给你发半封邮件。

  • 开始日期别手改到注册当天。新账号年初至今本来就是零消费，加上预算按美国太平洋时间切日，填北京时间当天反而容易漏算刚开号前几小时的开销。

  1. 金额与操作：填入总额并开启邮件警报

预算类型选指定金额，目标金额填手里的总额 340 美元。

最后一步设提醒阈值，按 50%、90%、100% 设好（想盯得更细可以点添加阈值多加一档 25%），触发对象全选实际支出。

勾上下方的向结算管理员和用户发送邮件提醒，点底部完成收工。

五、第二步：全程点鼠标，开一台台湾服务器

回到控制台首页，先瞄一眼左上角顶部栏，确认当前选中的项目是 My First Project。

点开左上角三道杠导航菜单，找到 Compute Engine，点进子菜单里的虚拟机实例。

新账号第一次进这个页面需要先开权限，直接点启用开启 Compute Engine API，在原地等 1 到 2 分钟初始化走完。

跳转进虚拟机实例列表后，点下方的创建实例。

创建页面的表单很长，但真正需要我们动手的只有四处，其余全保持默认

  1. 机器配置：锁定台湾与 E2 机型

名称用系统默认生成的或者自己改成 tw-1 都行。

区域一定要下拉选到 asia-east1（台湾），右边的可用区保持不限或选 asia-east1-b。

往下滑到机器类型，保持在通用标签下，点选 E2 系列，预设规格选 e2-medium（2 vCPU、4 GB 内存）。

可能卡在哪：右侧估算默认 10 GB 磁盘显示 29.32 美元，下一步改 20 GB 后变 30.32 美元。

注意这个估算值没有包含公网 IPv4（约 3.65 美元/月）和流量费，别误以为一个月总共只扣 30 刀。

  1. 操作系统和存储：换 Debian 13 配 20 GB 磁盘

点左侧菜单的操作系统和存储空间，再点页面中间的更改。

操作系统选 Debian，版本确认是 Debian GNU/Linux 13 (trixie)。

启动磁盘类型保持平衡的永久性磁盘，把大小改成 20 GB，点底部选择确认。

  1. 数据保护：关掉备份省快照费

切到左侧的数据保护，把备份直接改成无备份，省得后台自动打快照偷偷吃你额度。

  1. 网络：确认临时 IP 与网络服务层级

切到左侧的网络，如果准备拿这台机器搭网站就把防火墙的 HTTP 和 HTTPS 勾上，平时自己跑工具不建站就不用勾。

点开下面的 default 网络接口，确认外部 IPv4 地址选的是临时。

最底下的 Network Service Tier（网络服务层级）按你前面选的方案填。

走方案 A 求好线路保持默认的高级，走方案 B 要每月 200 GB 免费流量就切到标准。

全部核对完点页面最下方的创建。

等大概半分钟，实例列表里亮起绿勾、刷出外部 IP，这台台湾服务器就正式落地了。

稳妥起见，点实例名字进详情页翻到网络接口那一栏，最后核对一眼网络层级没选错。

六、第三步：登录服务器（附 Claude Code 全自动接管）

机器跑起来后不用专门装一堆复杂的终端工具，下面两种方式挑顺手的用。

方法一：浏览器一键登录（最快上手）

在虚拟机实例列表或者详情页里，直接点那一行的 SSH 按钮。

浏览器会自动弹出一个网页终端连进服务器，免密码也免配密钥，进去先敲一行命令把系统软件包更新到最新：

sudo apt update && sudo apt upgrade -y

方法二：交给 Claude Code 自动管机器（零命令门槛）

如果你看到黑框命令行就头大，干脆把 SSH 权限交给电脑上的 Claude Code，以后装环境直接动嘴就行。

第 1 步，让 Claude 生成密钥。

打开本地 Claude Code 对它说：帮我生成一个连服务器用的 SSH 密钥。

它会在你电脑上跑类似下面这行命令，并把生成出来的一整行公钥发给你：

ssh-keygen -t ed25519 -f ~/.ssh/gcp_tw1 -N "" -C gcpuser

第 2 步，去控制台打开修改页面。

回到 Cloud 控制台点进这台虚拟机的详情页，点击顶部的修改按钮。

第 3 步，把公钥填进服务器。

往下翻到安全和访问区域的 SSH 密钥，点 + 添加项，粘进整行公钥后滑到页面最底部点保存。

第 4 步，把外部 IP 发给 Claude 连接。

把控制台显示的服务器外部 IP 发给 Claude Code，它会自动拿公钥末尾的用户名（比如 gcpuser）连上去干活：

ssh -i ~/.ssh/gcp_tw1 gcpuser@你的外部IP

可能卡在哪，两个细节留神：

  • 复制公钥时必须从 ssh-ed25519 开头完整复制到末尾用户名，少一个字符都连不上

  • 私钥全程留在你本地电脑上，哪天想收回权限，回控制台把那行公钥删掉就当场断连

七、日常使用的五个避坑提醒

机器顺利跑起来之后，平时用的时候留意这五件事，能省掉九成以上的账单惊吓：

  • 关机重启会换公网 IP：默认的临时 IP 在关机再开机后会变。确有固定 IP 需求去 VPC 网络下面的 IP 地址里把它提升为静态（网络层级保持一致），但切记机器关停让静态 IP 闲置时，单价反而翻倍涨到 0.01 美元/小时

  • 点停止不代表完全停费：虚拟机停止后算力不收钱，但挂载的那块 20 GB 磁盘照样按月计费，彻底不用的机器直接点删除

  • 不通的端口去防火墙放行：默认只开了 22 端口（SSH），自己部署网页或服务连不上时，去 VPC 网络下面的防火墙加规则，用哪个端口开哪个端口

  • 每周巡检一次流量费：进结算下面的报告，按 SKU 搜索 Network Internet Egress，这一项就是你花掉的真实出站流量钱

  • 严禁卖号或帮别人代跑：这类行为直接撞 Google 高压线，封起号来不光云平台清零，还会连累你的主 Google 账号一起出事

八、90 天试用到期会怎样？如何做到一分钱不扣

最后把退场底线交个底，确保你从头到尾一分冤枉钱都不掏：

  • 死守不升级就绝对不扣卡：只要一直停留在试用账号状态，期间所有消耗全走赠金抵扣

  • 自动停机触发线：300 美元试用金花完，或者满 90 天，哪个先到就按哪个关停。停机后留 30 天宽限期给你拷数据，满 30 天彻底销毁

  • 两笔赠金混用时的隐藏边界：官方写死的关停条件是 300 美元试用金用完，如果 300 美元先见底或者满了 90 天，同一个结算号里还没花完的 40 美元订阅赠金很可能来不及花就跟着停摆。最稳的策略是直接按 300 美元封顶来规划，收到 90% 预算提醒邮件当天就把重要数据备份出来

  • 到期后还想接着免单用：如果你后续每个月还有 Ultra 赠金进账，在试用到期前先把机器降配到月度赠金能包住的规格（比如台湾 e2-small 配标准网络层级，每月约 21 美元），确认预算提醒正常后，再升级成付费账号接着用赠金抵扣

  • 只想留一台永久免费机：升级付费账号后，去美国 us-west1、us-central1、us-east1 任选一区开一台 e2-micro（含 30 GB 标准磁盘和每月 1 GB 出站流量），在 Google Cloud 规则下属于永久免费额度
